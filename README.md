# notaelabs-skills

Agent skills from Notae Labs.

| Skill | Purpose |
| --- | --- |
| [`logomark`](./logomark/) | Iterative SVG logomark pipeline (4 drafts → select/fix → final) |

## Install

Copy or symlink a skill folder into your agent skills directory, e.g.:

```bash
ln -s "$(pwd)/logomark" ~/.cursor/skills/logomark
# or for Claude Code:
ln -s "$(pwd)/logomark" ~/.claude/skills/logomark
```
